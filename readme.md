# Connect-4

Connect 4 is a simple game best described as a 6 x 7 tic tac toe board.

## Functions
- main() : the main game loop
- drawBoard() : prints the 6 x 7 board to the terminal
- move(symbol) : takes input and updates the board accordingly with the corresponding move
- whoWon(symbol) : checks which symbol won and prints the final win statement.

## How to run

1. Clone the repo:

git clone https://github.com/shezanusdf/connect4

2. Run the game

cd connect4
python connect_four.py

## How to play

Try to get as close as 21 without going over.
face cards = 10
ace = 11 or 1
